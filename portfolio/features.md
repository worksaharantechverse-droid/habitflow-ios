# Features — HabitFlow

## Verified in the iOS 26 simulator

- Three-tab navigation: Today, Habits and Insights.
- Today screen shows date, progress ring, completion count and habit rows.
- One-tap completion toggles update streaks and progress immediately.
- Habits screen supports add, edit and swipe-to-delete.
- Editor provides name, icon, colour and daily reminder hour selection.
- Insights shows best streak, total completions, monthly rate and a weekly Swift Charts bar chart.
- Month calendar lists the selected habit's history and allows toggling past days.
- Demo habits are seeded on first launch.
- Adaptive light and dark styling.
